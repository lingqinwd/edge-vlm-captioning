# Formal evaluation dataset

`data/images/` now contains 27 deterministic synthetic images generated by `generate_synthetic_dataset.py` plus the original five smoke-test images. They are grouped into object, pattern, scene, animal, text and abstract categories, and contain no personal data or third-party material.

`manifest.csv` records each filename, category, local source and reference caption. Use the same 27 files for every model and precision setting. The reference captions are only for later evaluation; they are not passed to the model during inference.

To regenerate the 22 extended images:

```powershell
python data/generate_synthetic_dataset.py
Copy-Item sample_images\\*.png data\\images\\ -Force
```

For a stronger final report, keep this dataset as a reproducible engineering benchmark and add a separate licensed real-image set if course rules permit it.
